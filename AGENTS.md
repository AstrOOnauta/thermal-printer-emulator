# AGENTS.md

Thermal Printer Emulator: a Tauri v2 desktop app (Rust core + React/TypeScript webview)
that emulates an ESC/POS network receipt printer (a virtual thermal printer).

**Before any work, read [`.ai/rules.md`](.ai/rules.md).** It is the project's rulebook and
links to the rest of the context in [`.ai/`](.ai): stack, conventions and flows.
